# @truepath/integrations

`IntegrationAdapter` implementations for Shopify, Meta Marketing API/CAPI, Google Ads and
Shiprocket (SPEC §8), one subfolder per provider so a version bump is contained to its adapter.

Empty scaffold as of M0-1. Provider subfolders and adapters are added starting M1-1 (Shopify);
see `docs/architecture/lld/shopify-integration.md`, `meta-integration.md`,
`google-ads-integration.md`, `shiprocket-integration.md`.
